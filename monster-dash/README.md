# 👾 Monster Dash – Enhanced Edition

Fast-paced 2D action game for kids! Play as Luigi (and Mario in 2P mode), shoot pop-culture enemies, collect bonuses, and defeat the boss!

## 🚀 How to Play
Open `index.html` in Chrome or Edge. No install needed.

## 🎮 Controls

### Player 1 – Luigi 🟢
| Key | Action |
|-----|--------|
| ← / A | Move Left |
| → / D | Move Right |
| ↑ / W | Jump (press again mid-air = **Double Jump!**) |
| Space | Shoot |

### Player 2 – Mario 🔴 (2P mode)
| Key | Action |
|-----|--------|
| J / L | Move |
| I | Jump / Double Jump |
| K | Shoot |

### Global
| Key | Action |
|-----|--------|
| P | Pause / Resume |
| F | Fullscreen |
| R | Restart (Game Over) |
